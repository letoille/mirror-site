关于 魔镜

魔镜（Mirror）是面向《流放之路》1 & 2（POE1 · POE2）的桌面悬浮窗助手，可在不切出游戏的前提下完成查价、攻略查阅与收益统计。下载后开箱即用。

01魔镜是什么

魔镜是运行于 Windows 的《流放之路》桌面辅助工具，以悬浮窗形式将常用信息叠加于游戏画面之上。在游戏内悬停一件物品并按下热键，即实时查询官方市集的挂单价并显示在物品旁，全程无需切出游戏或手动打开网页。查价之外，另整合截图识别、剧情引导、快捷正则、通货兑换、计时器、奖励掉落统计等刷图常用功能。

02核心功能

  • 物品查价：悬停物品一键查询官方市集实时价格。
  • 截图识别查价：一帧截图本地识别整屏物品名并批量查价。
  • 剧情引导：自动识别所在区域，跟随切换任务与导航。
  • 快捷正则：将常用正则保存为卡片，一键复制到商店或仓库搜索框。
  • 通货兑换 / 计时器：实时通货比率与全局+地图计时。
  • 奖励计数 / 收益统计：统计刷图掉落与收益，得出资产总值、每小时收益与每图收益。两代通用，区别在于资产来源——流放之路 1 读取仓库，流放之路 2 读取交易站上的公开挂单。
  • 掉落过滤器：基于 NeverSink 定制的开荒 / 刷图 / 速刷三份，跟着经济数据更新，另有语音版，客户端可一键装进游戏目录或你的 GGG 账号。
  • 游戏内 BD 天赋规划器：把构筑写成游戏认的 .build 文件，天赋走线直接画在游戏自带的规划器里，内置 33 套 BD，开荒与终局两套天赋分别给。
  • 速查图：Shift+Space 唤出自行上传的速查图缩略图带，悬停后以原尺寸展开于游戏中央。
  • 魔镜市集（网页）：trade.kalandraeye.com —— 词缀池随物品类别收窄的交易搜索、基于 Path of Building 本体的角色试装，以及由一句话填写表单的 AI 助手。

03支持范围

  • 两代游戏：《流放之路》1 与 2（POE1 · POE2）。
  • 三大服务器：国际服 / 国服 / 台服。
  • 三种语言：英文 / 简体中文 / 繁体中文。
  • 键盘 + 手柄：所有功能均可由手柄按键触发。
  • 系统要求：Windows 10 / 11（64 位）。
  • 两个入口：Windows 客户端（悬浮窗）与网页版魔镜市集，后者在浏览器中即可使用。

04安全与隐私承诺

魔镜绝不注入、读取或修改游戏进程与内存，也不修改任何游戏文件。它只会：读取游戏的日志文件、读取你主动复制的物品文本、以及在你按下识别热键时截取一帧屏幕做本地 OCR。所有查价均通过官方市集 API 完成，工作方式与官方交易网站一致。

物品识别全程在你本地电脑完成，不上传截图或账号信息。国服交易搜索需要你在设置中自行填入会话 Cookie，该信息仅保存在本地、仅用于向官方接口发起查询。请你同时自行遵守游戏的服务条款。
