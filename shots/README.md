# 演示截图 / Demo screenshots

首页那十张功能卡的配图。**从视频换过来的**：原先每张卡是一段 mp4，滚完首页要拉
**9.8 MB**；同样十张图大约 **1 MB**，省 90%。顺带解决了三件事——移动端省流量 /
低电量模式本来就拦 autoplay（那些卡在手机上永远停在占位图）、静帧带 `alt` 能进
Google 和百度的图片搜索（裸 mp4 没有 `VideoObject` schema、没有字幕，搜索引擎读
不出任何东西）、以及读者能自己控制节奏。

`price` 那张**仍然是视频**（`demos/price_{zh,en}.mp4`）：一键查价是首屏核心卖点，
值那 1.3 MB。其余九张都换成了图片。

## 要出哪几张

文件名就是卡片的 key。每张各出 **`.webp` 和 `.avif` 两份**，尺寸照下表——
`<img>` 上写死了 `width`/`height`，比例对不上会被拉变形。

| 文件名 | 比例 | 建议像素 | 画什么 |
|---|---|---|---|
| `scan`     | 3/4   | 900×1200  | 截图识别：整屏物品名被框出来，旁边带价格 |
| `campaign` | 4/3   | 1200×900  | 剧情引导浮层：当前区域的任务 / 奖励 / 技能宝石 |
| `ai`       | 16/10 | 1440×900  | 魔镜市集 AI 助手：一句话之后表单被填好的样子 |
| `wealth`   | 16/10 | 1440×900  | 收益统计：追踪资产总值 + 每小时收益 + 每图收益 |
| `regex`    | 3/4   | 900×1200  | 快捷正则卡片浮在游戏上 |
| `unique`   | 3/4   | 900×1200  | 快速搜索：三语模糊匹配出结果 |
| `exchange` | 16/10 | 1440×900  | 通货兑换比率条 |
| `reward`   | 3/4   | 900×1200  | 奖励计数：刷图次数 + 掉落 + 总收益 |
| `timer`    | 16/10 | 1440×900  | 计时器：全局 + 当前地图 |

> `wealth` 和 `reward` 从来就没有过素材（`demos/` 里没有 `wealth_*` / `reward_*`），
> 这两张卡在线上一直停在占位图。

## 转换

```bash
# PNG → WebP + AVIF（cwebp / avifenc 来自 webp 与 libavif）
cwebp  -q 82 shots/scan.png -o shots/scan.webp
avifenc --min 24 --max 32 shots/scan.png shots/scan.avif
# 或者一条 ImageMagick
magick shots/scan.png -quality 82 shots/scan.webp
```

目标：单张 WebP **≤ 120 KB**。UI 截图里全是文字和细线，`-q` 压太狠会糊。

## 两个坑

- ⚠️ **服务器的长缓存正则不含 `.avif`**。nginx 那条是
  `\.(css|js|png|ico|jpg|jpeg|svg|webp|woff2?)$`（见 `DEPLOY.md`）——不把 `avif`
  加进去，AVIF 每次访问都重新下载，省下来的流量原样还回去，而且**不会报任何错**。
- ⚠️ **文件没到位时不会有破图**。`<picture>` 默认 `opacity:0`，只有 `img` 真的
  `load` 了才加 `.ready` 显出来；否则底下那层 CSS 画的 mock 原样留着。所以这些图
  可以一张一张补，补一张上一张。

## alt 文案

`alt` 直接写在 `index.html` 的 `<img>` 上，是中文的——**它是图片搜索唯一读得到的
东西**，不要清空、也不要写成 "screenshot"。将来拆出 `/en/` 那份时，英文页要换成
英文 alt（同一张图、两份标记）。

## 首页 hero 轮播（另一组）

首页右侧那块从单张 CSS 卡片改成了**轮播**。第一张永远是原来那张 CSS 画的物品卡——
所以一张截图都没有时，首页和从前完全一样：不画圆点、不自动播。

| 文件名 | 比例 | 建议像素 | 画什么 |
|---|---|---|---|
| `hero-scan`   | 4/3 | 1200×900 | 截图识别：整屏物品被框出来，旁边带价格 |
| `hero-wealth` | 4/3 | 1200×900 | 收益统计：资产总值 + 每小时收益 + 每图收益 |
| `hero-market` | 4/3 | 1200×900 | 魔镜市集网页：选定类别后收窄的词缀池与结果 |

这三张是**首页门面**，比功能卡那组更值得花时间：最好是真实游戏画面上叠着浮层，
而不是纯界面截图。

⚠️ **缺图不会留空白帧。** 图片幻灯要 `load` 成功才由 JS 纳入轮播，失败的整张移除
（`assets/shell.js` 的 `.hero-deck`）。所以这三张可以一张一张补，补一张多一张。

⚠️ **顺序可调。** 真实截图齐了之后，如果希望首屏直接是实拍而不是 CSS 卡片，把
`src/pages/index.zh.html` 里 `class="hero-slide is-mock"` 那一整块移到其余幻灯之后即可，
JS 按 DOM 次序播。

⚠️ **轮播的 `alt` 也走翻译表**（`src/i18n/index.json`）。`i18n-tool` 现在会收 `alt=""`
的值——早先它只收文本节点，结果英文页和繁中页的图片 `alt` 全是简中，而那是图片搜索
唯一读得到的东西。
