關於 魔鏡

魔鏡（Mirror）是面向《流亡黯道》1 & 2（POE1 · POE2）的桌面懸浮窗助手，可在不切出遊戲的前提下完成查價、攻略查閱與收益統計。下載後開箱即用。

下載魔鏡 查看全部功能

01魔鏡是什麼

魔鏡是執行於 Windows 的《流亡黯道》桌面輔助工具，以懸浮窗形式將常用資訊疊加於遊戲畫面之上。在遊戲內停在一件物品上並按下熱鍵，即時查詢官方市集的掛單價並顯示在物品旁，全程無需切出遊戲或手動開啟網頁。查價之外，另整合截圖辨識、劇情引導、快捷正則、通貨兌換、計時器、獎勵掉落統計等刷圖常用功能。

02核心功能

  • 物品查價：停在物品上一鍵查詢官方市集即時價格。
  • 截圖辨識查價：一幀截圖在本機辨識整螢幕物品名並批次查價。
  • 劇情引導：自動辨識所在區域，跟著切換任務與導航。
  • 快捷正則：將常用正則儲存為卡片，一鍵複製到商店或倉庫搜尋框。
  • 通貨兌換 / 計時器：即時通貨比率與全域＋地圖計時。
  • 獎勵計數 / 收益統計：統計刷圖掉落與收益，得出資產總值、每小時收益與每圖收益。兩代通用，區別在於資產來源——流亡黯道 1 讀取倉庫，流亡黯道 2 讀取交易站上的公開掛單。
  • 掉落過濾器：基於 NeverSink 定製的開荒 / 刷圖 / 速刷三份，跟著經濟資料更新，另有語音版，客戶端可一鍵裝進遊戲目錄或你的 GGG 帳號。
  • 遊戲內配裝天賦規劃器：把配裝寫成遊戲認得的 .build 檔案，天賦走線直接畫在遊戲自帶的規劃器裡，內建 33 套配裝，開荒與終局兩套天賦分別給。
  • 速查圖：Shift+Space 喚出自行上傳的速查圖縮圖帶，停留後以原尺寸展開於遊戲中央。
  • 魔鏡市集（網頁）：trade.kalandraeye.com —— 詞綴池隨物品類別收窄的交易搜尋、基於 Path of Building 本體的角色試裝，以及由一句話填寫表單的 AI 助手。

03支援範圍

  • 兩代遊戲：《流亡黯道》1 與 2（POE1 · POE2）。
  • 三大伺服器：國際服 / 國服 / 台服。
  • 三種語言：英文 / 簡體中文 / 繁體中文。
  • 鍵盤 + 手把：所有功能均可由手把按鍵觸發。
  • 系統需求：Windows 10 / 11（64 位元）。
  • 兩個入口：Windows 客戶端（懸浮窗）與網頁版魔鏡市集，後者在瀏覽器中即可使用。

04安全與隱私承諾

魔鏡絕不注入、讀取或修改遊戲行程與記憶體，也不修改任何遊戲檔案。它只會：讀取遊戲的日誌檔案、讀取你主動複製的物品文字、以及在你按下辨識熱鍵時擷取一幀螢幕做本機 OCR。所有查價均透過官方市集 API 完成，運作方式與官方交易網站一致。

物品辨識全程在你本機電腦完成，不上傳截圖或帳號資訊。國服交易搜尋需要你在設定中自行填入工作階段 Cookie，該資訊僅保存在本機、僅用於向官方介面發起查詢。請你同時自行遵守遊戲的服務條款。

05關於團隊與非官方聲明

魔鏡由一個獨立的玩家團隊開發與維護。下載與核心功能免費；少數功能（魔鏡市集、過濾器一鍵安裝、設定雲端同步、AI 類功能）由會員支應，用於支付伺服器與模型成本。我們持續根據社群回饋迭代。
