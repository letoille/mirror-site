About us

About Mirror

Mirror is a desktop overlay for Path of Exile 1 & 2 (POE1 · POE2) that handles price checks, guide reference and profit tracking without leaving the game. Ready to use as soon as it is downloaded.

Download Mirror See all features

01What Mirror is

Mirror is a Windows desktop companion for Path of Exile that overlays the information you need on top of the game. Hover an item in game and press a hotkey: it queries live listings from the official trade API and shows the price beside the item, without leaving the game or opening a browser. Beyond pricing it integrates screen scanning, a campaign guide, regex presets, currency rates, timers and drop tallies.

02Core features

  • Item pricing — hover an item, one hotkey, live official-trade prices.
  • Screen scan — one frame, local OCR reads every item name on screen and prices them all.
  • Campaign guide — detects your zone and switches tasks and navigation along with you.
  • Regex presets — keep frequently used expressions as chips and copy one into a vendor or stash search in a click.
  • Currency rates & timers — live exchange rates, plus a global and a per-map clock.
  • Drop tally & wealth tracking — track drops and profit, reporting total asset value plus income per hour and per map. Available in both games; only the source differs — Path of Exile 1 reads your stash, Path of Exile 2 reads your public trade listings.
  • Loot filters — Pushing / Farming / Speed, built on NeverSink's and kept current with economy data, each also with alert sounds; the client installs them into the game folder or your GGG account in one click.
  • In-game build planner — writes your build into a .build file the game itself reads, so the passive route is drawn in the game's own planner. 33 builds included, each with a separate levelling and endgame tree.
  • Cheat sheets — Shift+Space brings up a strip of images you uploaded; hover one and it opens at full size in the centre of the game.
  • Mirror Market (web): trade.kalandraeye.com — trade search whose modifier pool narrows to the item class, character try-on running Path of Building itself, and an AI assistant that fills the form from a single sentence.

03What it supports

  • Both games — Path of Exile 1 and 2 (POE1 · POE2).
  • Three realms — Global / China / Taiwan.
  • Three languages — English / Simplified Chinese / Traditional Chinese.
  • Keyboard + gamepad — every feature can be triggered from a gamepad button.
  • System — Windows 10 / 11 (64-bit).
  • Two ways in — the Windows client (overlays) and Mirror Market, which runs in any browser.

04Safety & privacy

Mirror never injects into, reads or modifies the game process or memory, and never modifies any game file. It only ever: reads the game's log file, reads item text you copy yourself, and captures one screen frame for local OCR when you press the scan hotkey. All price lookups go through the official trade API , exactly the way the official trade site works.

Item recognition runs entirely on your own PC — no screenshots or account details are uploaded. The China-realm session cookie you enter is stored locally and used only to query the official endpoints. Please also follow the game's Terms of Service.
