# 掉落過濾器怎麼裝

《流亡黯道》2 中，單張地圖掉落的物品絕大多數不具備撿取價值。掉落過濾器決定**哪些顯示、哪些完全不繪製於地面**，並可為高價值物品附加提示音與光柱。

這是本作中**效益最高的一項設定**：一次安裝，此後每張地圖均可節省時間。

## 我們發的是什麼

我們不自行撰寫過濾規則，而是轉發 **[NeverSink](https://github.com/NeverSinkDev)** 的版本——社群公認的那一份，採用 MIT 授權。我們所做的是依據目前經濟資料定製，並劃分為三份：

| 哪一份 | 適合什麼時候 |
|---|---|
| **開荒** | 自開局至異界 T15。顯示範圍較寬，避免遺漏 |
| **刷圖** | T15 階段：升級裝備、累積通貨、補齊配裝所缺部件 |
| **速刷** | 配裝成型之後。僅保留高價值物品，地面顯著簡潔 |

每一份另提供**帶語音的版本**：高價值物品掉落時給出語音提示。

⚠️ 語音版只有《流亡黯道》2 有。POE1 不支援自訂提示音，所以那幾份不會出現在介面裡。

**三份可同時安裝**，遊戲內隨時切換，無需預先取捨：開荒階段使用開荒，進入刷圖階段後更換即可。

## 方式一：客戶端一鍵安裝（建議）

打開魔鏡客戶端 →「過濾」頁 → 選一份 → 裝。

客戶端將執行兩項操作：寫入遊戲目錄，並推送至你的 GGG 帳號，以便在其他裝置登入時同樣可用。裝入遊戲後的名稱形如 `魔鏡 - 開荒`，帶語音的版本為 `魔鏡 - 開荒語音版`。

此後客戶端將持續追蹤版本：上游更新、介面語言變更或語音包更換時，均會提示重新安裝。

> 查看是否存在新版本無需登入；**安裝**則需要登入並開通。兩者分開處理：過濾檔案本身不收費，詳見下一節。

## 方式二：手動放入目錄

若不希望登入，或僅需試用，可直接下載檔案：

**[trade.kalandraeye.com/tw/filters](https://trade.kalandraeye.com/tw/filters)**

三份及其語音版均可自由下載。下載後放入：

```
Documents/My Games/Path of Exile 2/
```

⚠️ 若已啟用 OneDrive 備份，`Documents` 可能已被重新導向至其他位置。請以遊戲內能否識別為準，不要手動拼接路徑。

語音版的 mp3 也放同一個目錄。

## 在遊戲裡切換

<kbd>Esc</kbd> → **選項** → **介面** → 從下拉選單裡選中它。

安裝幾份即有幾個選項，可隨時切換，無需重開遊戲。

## 什麼時候該換一份

- **地面物品過多、難以辨識** → 向「速刷」方向調整
- **疑似遺漏應撿取的物品** → 向「開荒」方向調整
- **賽季初** → 先用開荒，T15 穩定後更換為刷圖
- **上游更新** → 客戶端會提示；手動安裝者可定期查看下載頁

## 常見問題

**安裝後沒有變化。** 請先確認遊戲內已選中該過濾器（見上一節三步）。過濾器不會自動生效，必須在選項中選定。

**沒有提示音。** mp3 需與過濾檔案位於同一目錄。此外我們疊加的是「可選提示音」，檔案缺失不會使整條規則失聲，因此也可能只是未觸發該條規則。

**是否存在封號風險。** 掉落過濾器是**遊戲官方支援的功能**，Esc 選單中的下拉選單即由官方提供。它只是一個文字檔，不接觸遊戲行程。
